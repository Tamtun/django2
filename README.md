# Django Homework Project 📘

Учебный проект на Django для выполнения домашних заданий в рамках курса.

## 📦 Структура репозитория

- `main` — стабильная, протестированная версия
- `develop` — ветка активной разработки
- `homework-*` — отдельные ветки для заданий (например, `homework-1`, `homework-2` и т.д.)

## 🚀 Установка и запуск

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/<твой-никнейм>/<название-репо>.git

2. Перейди в папку проекта:
   ```bash
   cd <название-репо>

3. Установи зависимости:
   ```bash
   pip install -r requirements.txt

4. Запусти сервер:
   ```bash
   python manage.py runserver

## 🛠️ Используемые технологии
- `Python 3.12`

- `Django 5.2`

- `Git (с GitFlow)`

- `Виртуальное окружение (venv)`
- `Boostrap`
